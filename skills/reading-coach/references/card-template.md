# 知识卡片模板

卡片是这一轮的产物，也是唯一会留在磁盘上的东西。写坏了，用户下次翻回来看到的是一段正确的废话。

## 骨架

```
📚 知识卡片：<章节名>

1️⃣ 一句话要点
<一句话>

2️⃣ 因果链
<场景> → <原因> → <代价> → <结果>

3️⃣ 解决方案
- 步骤一：…
- 步骤二：…
- 步骤三：…

4️⃣ 边界条件
适用于：…
不适用于：…

5️⃣ 原句
- 「…」（第 N 章）
- 「…」（第 N 章）
```

## 逐维说明

### 1 一句话要点

动词开头，主语和结果都要在句子里。

- 好：「把决策写进流程，公司就不再依赖创始人拍板」
- 坏：「造钟人思维很重要」——这是评价不是要点
- 坏：「关于组织建设的思考」——没有内容

### 2 因果链

四段，用箭头连。每段都是一个具体动作或具体后果，不要抽象名词堆叠。

- 好：「老板每件事都要过问 → 中层不敢定 → 人全跑了 → 老板更不敢放手」
- 坏：「管理不善 → 效率低下 → 影响发展」——三个词都没落地

### 3 解决方案

三到五条，每条能照着做。要结合这个用户自己的处境（学生、写作者、要考研、要进院所），不要写成「企业应当加强管理」这种给所有组织的建议。

- 好：「这个月内把自己的三个决定写成规则，贴在书桌前」
- 坏：「建立制度化的决策流程」

### 4 边界条件

这一段最容易糊过去。必须写出一个具体的反例人群或场景。

- 好：「适用于人手超过五个、事情开始重复发生的团队；三个人以内、天天见面的小组不需要流程，加流程反而慢」
- 坏：「视情况而定」

### 5 原句

只抄书上真有的话，逐字，标章节。不许改写、不许把两句话拼成一句、不许「大意是」。

找不到合适的句子就写：「这一节没有可直接引用的原句」。这比编一句强。

## 写完之后自查

- 五个维度齐了吗，有没有偷偷合并。
- 一句话要点里有没有「重要」「关键」「核心」这类填充词。
- 因果链四段是不是都在讲同一件事。
- 解决方案能不能被我照着做。
- 原句能不能在书的原文里搜到。

有一条不过就重写那一维，不要把卡片整张推倒。
