# 多篇对比的判据

多篇放一起时，最常见的两种错是：把口径差异写成真矛盾，把真矛盾写成「各有道理」。这一份给可操作的判定步骤。

## 一、四步排查：这两个结论真的冲突吗

按顺序走，任何一步消解了冲突，就停在那一 步，不要再往下判。

### 第一步：问的是同一个问题吗

把两篇的主张各写成一句问句，看是不是同一个。

- A：「在长文档上，先切块再检索能不能提升准确率」——这是效果问题。
- B：「长上下文直接喂，工程上是否可接受」——这是成本问题。

两个问题不同，结论相反很正常，不构成矛盾。写综述时要分开成两组，或者在同一组里用「前者问效果，后者问成本」一句交代过去。

### 第二步：评测口径一样吗

四项逐对：

| 项 | 要看什么 |
| --- | --- |
| 数据 | 同一数据集？同一切分？训练与测试是否重叠 |
| 指标 | 同一指标？同一计算方式（宏平均 / 微平均）|
| 基线 | 是否与同一基线比；基线是原论文复现还是自实现 |
| 设置 | 模型规模、上下文长度、是否调参到最优 |

四项里有一项不同，两个数字就不能直接比；两项以上不同，连「大致相当」都不能说。

### 第三步：结论范围一样吗

- A 说「在我们的设定下 X 有效」，B 说「X 普遍有效」。范围不同是覆盖关系，不是矛盾。不要把一句限定结论当成普遍结论再拿去对撞。
- 真正要对撞时，先统一到同一范围：都缩到「英文新闻域、十亿参数以下」。

### 第四步：还剩冲突，就是真矛盾

走到这一步，写清三件事：

1. 两边各自的证据是什么（数据集、指标、样本量）。
2. 差异最可能来自哪一环（数据、基线、调参、实现）。
3. 需要什么样的实验才能裁决。

真矛盾不要和稀泥。写「目前无法判断」时要给出裁决实验，否则读者会以为你在回避。

## 二、什么算真矛盾

同时满足三条才算是：

- 同一个问题。
- 可比的设置（或差异已经被解释掉）。
- 结论方向相反：一个说显著有益，一个说无益或有害。

只有前两条、结论只是强弱不同（一个说提升 5 点，一个说提升 1 点），那是**幅度差异**，不是矛盾。幅度差异通常说明设置不同，回到第二步。

## 三、什么算口径不同

- 数据集不同，尤其是一个自建、一个公开。
- 指标不同（F1 对准确率，BLEU 对人工评分）。
- 切分不同（按文档切还是按段落切，随机切还是按时间切）。
- 基线不同代（和两年前的版本比，和最新最强比）。
- 一个报了方差一个只报最好一次。

口径不同时，综述里的正确写法是「不可直接比较」，并说明差在哪一项。不要写「A 优于 B」，也不要写「两者相当」。

## 四、排序判断：四条依据

要给出「哪一条最经得起检验」时，只能用这四条，逐条过：

1. **对照公道**：与最强基线同设置比较，还是与弱基线或自实现基线比。
2. **可复现**：代码、数据、关键超参是否公开；流程能否照做。
3. **稳健性**：多数据集、多随机种子、方差与显著性。
4. **范围一致**：结论声称的范围与实测范围是否一致，有没有过度外推。

四条都过的，可以排第一。只过一两条的，写「方向有价值但证据尚薄」。一条都不过的，不要排进名次，单独放到「待核」里。

四条之外的因素——写作好坏、发表在哪个会议、作者是谁——不参与排序。会议上多转引几次不会让证据变强。

## 五、并列时的写法

真正分不出高下时，不要硬排。写：

> 这两条在现有证据下不可比：A 在自建数据上领先，B 在公开集上领先，两者没有交集数据集，也未互相复现。要比较，需要同一个公开集上的同设置实验。

这句话给了读者三样东西：现状、原因、下一步。比「各有优势」有用得多。

## 六、别做的四件事

- 不要把摘要里的数字当结果用。摘要常省方差与设置，拿它排名次必然失真。
- 不要用「多数研究认为」代替篇名。多数是几篇？没有实际统计就不写。
- 不要把一篇综述当成多篇证据。综述是二手，引用它时标明是综述转述。
- 不要为了故事顺而删掉反例。反例通常就是缺口所在，删了故事好看但结论会错。
