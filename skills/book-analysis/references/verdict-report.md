# 判读报告模板

报告的唯一目的：让用户在两分钟内决定要不要读这本、读到哪。它不是一个缩小的解析，也不是书评。

## 骨架

```
📖 判读报告：《书名》作者

一、归类
<体裁 / 年代 / 写法路数，一句话>

二、一句话主旨
<我自己的话，不许抄前言腰封>

三、核心问题
1. <问题>
2. <问题>
3. <问题，二到五条，少于两条说明没抓住>

四、骨架
<三到四句，分段与推进逻辑>

五、四维判断
难度：<需要什么前置知识>
密度：<每一页有多少东西>
质地：<文字稠疏冷热>
匹配：<跟用户当下要解决的问题多近>

六、建议
<四选一 + 一句理由>
```

全文四百字以内。超了就是没想清楚，砍到四百。

## 六个格子的写法

### 归类

一个句子里要塞下三样东西：什么体裁、大概什么时候、用的什么写法。别掉书袋，别列流派名。

- 好：「十九世纪的写实长篇，用第三人称全知视角，一章写一个人物，靠场景切换推进。」
- 坏：「批判现实主义杰作，深刻反映了时代。」
- 坏：「意识流小说，现代主义代表作，受柏格森影响。」——三个流派名，一个具体信息都没有。

### 一句话主旨

用动词组织，说清谁想干什么、被什么挡住。

- 好：「一个想靠体面活下去的人，一步一步发现体面本身就是要他命的东西。」
- 坏：「揭示了人性的复杂与社会的黑暗。」——所有书都能用。

抄前言是死罪。前言是作者或编者希望你记住的那句话，通常不是这本书真正在做的事。

### 核心问题

主题和问题的区别：主题是名词短语（「异化」「成长」「背叛」），问题是带疑问和代价的句子（「一个人为了不背叛朋友，能不能背叛自己一次？」）。

- 好：「一个已经被制度驯服的人，还有没有可能重新做一个决定？」
- 坏：「探讨了权力与自由的关系。」

二到五条。一条说明你只看到了表面，六条说明你还没分主次。

### 骨架

把书拆开再拼回去，看能不能拼回原样。三到四句，说清「前半本在做什么、转折在哪、后半本怎么收」。

能写出骨架，说明你理解了推进逻辑；写不出，说明你记住的是情节不是结构。骨架里不要出现人物名字的罗列，用功能描述代替（「一个被派去执行命令的人」而不是「张三」）。

### 四维判断

四维不是四个形容词，是四个可比较的量。

| 维度 | 问什么 | 写法 |
| --- | --- | --- |
| 难度 | 读它需要什么前置 | 「不需要先读别的，但要知道十九世纪俄国的农奴制怎么回事」 |
| 密度 | 一页里有多少东西 | 「一页能发生三件事，对话几乎没有停顿」或「一页只写一场雨」 |
| 质地 | 文字的手感 | 「句子短，刀口朝内，冷」或「句子长，绕，热，黏」 |
| 匹配 | 跟用户的目的多近 | 「你想练叙述视角，这本是教材级的样本；你想找故事看，它会让你闷」 |

四个维度里，匹配最重要。一本书好不好是公共问题，值不值得**你**读是私人问题。报告要给的是后者。

### 建议：四档，必须选一个

**第一档 · 值得精读（整本）**

什么时候给：骨架清晰、五个维度都有可讲的东西、跟用户的目的对得上。
理由要具体到「你会从哪一章学到什么」，不许写「经典值得一读」。

**第二档 · 只读某几章**

什么时候给：整本结构松散，但有几个章节是硬货；或者用户的目的只需要其中一部分。
必须点名章节，并说清抽出来的那几章能不能独立成立。举例：「读第九章到第十一章就够，前面是铺垫，后面是收束，这三章单独看也成立。」

**第三档 · 不值得精读**

什么时候给：书本身有问题（结构塌、论证空、语言糟糕），或者书没问题但跟用户的目的完全不搭。
两种情况的措辞不一样。书的问题要指出具体位置；不搭就要说「这本是好书，但你要的东西它不给」。

**第四档 · 有空再说**

什么时候给：书有价值，但需要读者先有某种状态——先读过某本、先有某种经历、先不着急。这一档不是敷衍，是给出条件。

不许和稀泥。「看你的需求」「各有优劣」「因人而异」——这些都不算建议。四个档位必须落一个，理由必须能被反驳（能被反驳才是判断）。

## 停下之后

报告写完，问一句：「按这个往下拆，还是先调整哪一项？」

然后**真的停**。等用户回话。常见的失败是报告给完，紧接一段「那我先说说结构」，把确认环节吃掉。用户没有确认，说明他还在判断这份报告靠不靠谱，你抢跑等于替他做了决定。

## 报告写坏了的样子

- **六项缺项**：少了骨架或四维，说明这份报告是印象不是判断。
- **主旨抄前言**：用户一眼能看出来，因为那句话他在封底见过。
- **全是形容词**：「深刻」「宏大」「细腻」——这些词不承载信息。
- **建议缺席**：报告读完，用户还是不知道读不读，那这份报告白写了。
- **超字数**：四百字以外的东西属于解析，不属于判读。
