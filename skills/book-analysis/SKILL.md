# 名著解析

## 你接的是什么活

用户把一本书、一章或一段文字交给你，说「分析一下」。这三个字下面藏着三种完全不同的请求，先分清：

- **摘要**：这本书讲了什么。网上到处都有，不做。
- **读后感**：我读完有什么感受。那是用户自己的事，你替他写等于替他感受。
- **分析**：这本书是**怎么写成的**，为什么这样写有效或无效，它在什么位置上。

只做第三种。判断方法很简单：分析关心的是「怎么做到」，摘要关心的是「说了什么」，读后感关心的是「我觉得怎样」。用户开口第一句如果是「这本书讲了啥」，先问一句他要的是情节梗概还是写法拆解；他说梗概，你可以给，但那不是这个 skill 的产物。

## 第一步：判读报告（必须先停）

在展开任何长文之前，先给一份判读报告，**四百字以内**，六项齐全：

1. **归类**：体裁、大致年代、写法路数（写实/寓言/意识流/章回/书信体……）。一句话，不要掉书袋。
2. **一句话主旨**：用你自己的话，不许抄前言、不许抄腰封。写不出就说明你还没读进去。
3. **核心问题二到五条**：这本书真正在追问的是什么。是问题不是主题——「人在制度里的变形」是主题，「一个人能不能在不伤害别人的前提下活下去」是问题。
4. **骨架重构**：你理解的分段与推进逻辑，三四句话。相当于把书拆成骨架再拼回去，拼不回原样说明你没读懂。
5. **四维判断**：难度（需要多少前置知识）、密度（每一页有多少东西）、质地（文字是稠是疏、是冷是热）、匹配（跟用户当下要解决的问题有多近）。每维一句话，给判断不给形容词堆。
6. **明确建议**，四选一，必须选一个，不许和稀泥：
   - 值得精读（整本）
   - 只读某几章（点名哪几章、为什么）
   - 不值得精读（说清是书的问题还是用户目的不匹配）
   - 有空再说（说明它适合什么状态下读）

**报告写完就停。** 问一句「按这个往下拆，还是先调整哪一项」，等用户回话再进第二步。不许自动接一篇五千字长文，那是把判读报告当摆设。

判断模板与四个档位的判别标准见 `references/verdict-report.md`。

## 第二步：五个维度，逐维挂原句

用户确认后进入解析。五个维度固定，顺序也固定，因为后一维依赖前一维的结论。

### 一、结构与推进

怎么分卷、分章、分节，为什么这么分。找出**枢纽**：哪一章（或哪一场）之后，整本书的重心变了。再看推进方式：是靠事件推、靠时间推、靠人物关系变化推，还是靠叙述者的思绪推。

要回答的是：如果抽掉某一章，这本书还成立吗。成立的章节是填充，不成立的才是结构。

### 二、人物与动机

谁在推动情节，谁的转变有代价，谁只是功能性的（出场只为传递信息或制造障碍）。动机要落到具体欲望上，不许写「他渴望自由」这种谁都能套的话——要写他为了这个欲望愿意失去什么。

特别看**动机与行为不一致**的地方。那是作者露手的地方，也是文本最结实或最松垮的地方。

### 三、视角与叙述方式

谁在看，用什么人称，叙述者知道多少，**看不到什么**。全知视角和限知视角的差别不在信息量，在于作者选择让读者跟谁一起被蒙在鼓里。注意叙述可靠性：这个叙述者有没有理由撒谎、有没有能力理解他看到的事。

再看时间处理：顺叙、倒叙、插叙，还是多线并置。时间的折叠方式往往就是主题本身。

### 四、语言与笔法

句子的长短、用词的冷热、对话与叙述的比例、比喻的密度与来路。这一维最容易被写成鉴赏散文，所以要盯住三件事：这句话如果换成另一种写法会损失什么；这个比喻是从哪个经验世界里取的；这一段的速度是快是慢，快慢服务于什么。

**每一条都必须挂原句。** 没有原句的笔法判断等于没判断。

### 五、文学史位置与同类对照

它在作者自己的写作序列里处在哪，在同时代的作品里处在哪，跟哪几本书可以放在一起比。对照要具体到「同一件事，A 这么写，它那么写，差别在哪」，不许只报书名。

这一维最容易变成掉书袋。判断标准：你给出的每个对照，都要能反过来解释前面四维里的某一处具体写法。解释不了就删掉。

五个维度各自的到位标准、以及「怎样算滑回摘要」的对照例，见 `references/five-dimensions.md`。

## 第三步：三层分离

解析里每一句话都要能归到下面三层之一，逐条标注，不许混成一段：

- **【作者主张】**：书里明说的观点、借人物之口说出的话、序跋里的自陈。
- **【书的证据】**：文本本身呈现的东西——某个情节、某句描写、某个重复出现的意象。这是可核对的部分。
- **【我的推断】**：你从证据推到主张的那一步，或者你判断作者没意识到的部分。

格式上就用方括号标在句首或句末。三层混在一起的典型症状是：读起来像在替作者说话，其实中间那一步是你自己加的。

**推断必须写清推断链**：从哪句原文，经过什么，得到这个结论。链断了就写「这里我推不下去」。

## 批判纪律

**理解之前不许批判。** 判读报告和五维解析没做完，不许说这本书「过时」「矫情」「结构松散」。没读懂就批评，批的是自己。

批判只允许四类，每条必须归到其中一类：

- **材料不足（uninformed）**：作者下判断时缺了哪类材料。要指出缺的是什么，不是笼统说「视野窄」。
- **信息错误（misinformed）**：事实层面错了。给出正确说法与依据。
- **推论不合逻辑（illogical）**：从前提到结论那一步不成立。把前提和结论都摆出来，指出断在哪。
- **论述不完整（incomplete）**：说了一半，反例没处理。给出那个反例。

四类之外一律不算批判，算审美偏好。审美偏好可以说，但要标明「这是我的口味，不是文本的问题」。

## 找不到依据怎么办

- 记不清是哪一章，就写「大约在全书后半，具体章节待核」，**不许编章节号**。
- 记不清原句，就写「大意是……（原句待核）」，**不许加引号伪造引文**。
- 完全想不起来，就说「这一点我找不到文本依据，先撤回」。

编一个页码比说一句不知道的代价大得多。用户拿你的引文去查，查不到，后面所有判断都不可信了。

## 输出格式

固定小节，顺序不乱：

```
一、判读结论（若已确认，一句带过）
二、结构与推进
三、人物与动机
四、视角与叙述
五、语言与笔法
六、文学史位置与同类对照
七、这本书的问题（四类批判，没有就写没有）
八、一句话总结：它值得读的地方在哪，不值得的地方在哪
```

每条判断后面括注依据，形如「（第三章，开篇那段关于雨的描写）」或「（原句：『……』）」。一整节下来一条依据都没有，这一节就是空的，删掉重写。

## 交付前自检

写完先自己过一遍这五条，不过就重写那一节，不要把整篇推倒：

1. **每一维有没有原句**。五个维度里任何一维通篇没有引文，这一维就是空的。
2. **有没有一节在复述情节**。连着三句以上在讲「然后他……」，删到只剩支撑判断的那一句。
3. **三层标注有没有漏**。扫一遍，凡是「作者显然想表达」这类句子，要么改成推断并给出推断链，要么补上原文依据。
4. **批判有没有归类**。每条批评前面有没有「材料不足 / 信息错误 / 不合逻辑 / 论述不完整」之一，没归类的是口味不是批判。
5. **建议是不是四选一**。判读报告里如果写的是「看情况」「因人而异」，重写。

篇幅不设下限。一本书写得薄，两千字解析到位就是到位；写得厚，也不要靠复述情节撑到八千字。字数是结果不是目标。

## 正文从哪来

按这个顺序取，前一个拿不到再用后一个：

1. **书架上的书**（dsh-reading 插件的书库）：先读书库目录下的文件，路径形态是 `~/.dsh-reading/dsh-reading/books/<bookHash>/`。
   - `meta.json` 里有书名、作者、格式、`spine`（章节表，每项含 `index` 与 `href`，EPUB 形如 `text/ch001.xhtml`，网络书形如 `ch/0001.xhtml`）与 `tocSource`（目录来源：`nav` / `ncx` / `headings` / `auto` / `spine` / `none`）。判读报告的归类、版本信息、章节结构从这里拿。
   - **目录本身不在 `meta.json` 里**，是打开书时按需解析出来的（`tocSource` 为 `none` / `spine` / `split` 的书根本没有真目录，只有 spine 顺序）。所以别照着 `meta.json` 声称「目录是这几章」；不确定就说「按 spine 顺序」。
   - 正文**不一定在磁盘上**：网络书（Legado 书源）打开过的章节会落在 `chapters/<N>.xhtml`，EPUB 与 PDF 是内存解析，书库目录里没有这个文件夹。所以先看一眼 `chapters/` 在不在，在就读对应的 `.xhtml`，不在就往下走第二条，不要凭空断言某个文件存在。
   - 不要在正文里让模型去调什么插件接口：这个插件没有给模型注册取书的工具，你手上只有文件系统和用户输入。
2. 用户在对话里贴进来的段落、章节或附件——这是最常用的一条。说清要什么：「把第一章的正文贴给我，或者告诉我章节名，我从书库里找文件。」整本解析一次读不完就一章一章来。
3. 只有书名：说清你能做到哪一步。「整本的分析我需要正文；如果你只是想先知道值不值得读，我可以凭公开的版本信息给一份判读报告，但里面不会有原句依据。」**这条边界必须说出口**，因为一份没有原句的判读报告和一个真正的解析，可信度差一个量级。

**不要凭书名编内容。** 没拿到正文就给判读报告时，每一处判断都要标成推断，不许伪装成读过。

## 不做的事

- 不写读后感。用户的感受是用户的。
- 不用内容摘要代替分析。复述情节不算解析。
- 不复述原文充篇幅。引原句是为了支撑判断，不是为了凑字数。
- 不美化也不猎奇。不因为写的是底层就写成苦难展览，也不因为写的是权贵就替他们开脱。
- 不因为它是名著就默认它好。名著也会写坏，指出来。
- 不在用户没确认判读报告之前开长篇。
