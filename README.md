# dsh-reading

在 DeepSeek 里读书的插件。导入 EPUB、MOBI、AZW3、TXT、PDF，分页读，翻目录，记住读到哪，划线做笔记。没有账号，没有服务器，书和笔记都在你自己的磁盘上。

## 装

桌面版 DSH 在插件管理里装这个目录。profile 是应用独占的，命令行 `dsh plugin` 会拒绝写 desktop。

命令行版：

```
dsh plugin --profile web add /path/to/dsh-Reading
```

`--profile`要放在 add 前面，写后面会被当成 pnpm 参数。装完重启 DSH，插件清单在启动时定。重启后左侧栏底部图标条里多一本打开的小册子，点它进书架。

卸载不会删书和笔记。

## 书和笔记在哪

默认 `~/.dsh-reading/`，配置项 `libraryDir` 可以改。全是 JSON 和 JSONL，没有数据库。备份就是复制这个目录。

删掉一条标注不是把行删掉，是标成已删除，那一行还在。多设备合并要靠它。解不开的位置单独记在一个只增不减的文件里，不进渲染，但记录留着。

## 能做什么

书架。封面、进度圈、最近在读。点封面进阅读。导入可以选文件也可以直接拖进窗口。卡片右键是编辑：书名、作者、简介、分类、系列、标签、珍藏、换封面。

左上角两级下拉筛书架：全部、珍藏、系列、作者、分类、标签。筛选只在前面算，不动书的数据。

导入面板三段：从电脑选文件、粘贴下载直链、用自己填的书源搜关键词。插件不带任何站点，也不带默认书源。

五种格式。EPUB 原样渲染，插图版式都留。MOBI 和 AZW3 重排成纯文字，书架上标「重排」。TXT 重排，自动认 UTF-8 / UTF-16 / GB18030，按「第 X 章」切章。PDF 只读文字版，扫描件和加密件打不开。重排书的划线、笔记、进度和 EPUB 一样。

阅读。分栏分页，翻页点正文两侧窄边、键盘左右、滚轮、两指横滑，一次手势只翻一页。字号、行高、栏宽、明暗在阅读视图的设置里调，改完立刻生效也立刻落盘。

目录。章节树，当前章节高亮，点一下跳。三种来源会在面板上标明：真目录、自动识别（按「第 X 章」认出来）、这本书没有目录。正文里那页手打目录，章节名是链接的也能点，跨文件锚点认，脚注留本章，外链问要不要用浏览器打开。

进度。关书存位置，重开回到原处，不是回到某个百分比。

划线和笔记。选中正文出菜单，五色高亮，一条高亮可以再挂笔记，书签不依赖选中。侧栏列出本书全部标注，按章节、按颜色筛，点一条跳回去。

划过的线能点。点一下已有高亮进入选中态，浮出操作条：换颜色、写笔记、问 AI、删除（5 秒内还能撤销）、双击复制整条。键盘也能用，Tab 聚焦，Enter 选中，Delete 删除，Esc 收起。

同一段不许划第二次。重叠时会亮出已有那条并提示「这段已经划过线了」，老数据叠了也只画一层。

问 AI。圈一段话，点问 AI，在输入框写问题，回答显示在下面，同时带着这段原文的位置存进这本书的问答记录。下次翻回来还能找到问过什么、答了什么、问的是哪一段。回答只用这段原文和通识，不确定就说不确定；小说会刻意不剧透后面。要走宿主自己的子代理，所以得先在 DSH 里选一个模型。

书源。支持 Legado 书源，填自己的源，抓目录、按章取正文。

## 配置

装完就能用。要改在 profile 的 `cordis.patch.yml` 里按行 id 覆盖：

```yaml
- id: reading
  name: 'dsh-reading'
  config:
    libraryDir: /Volumes/books/dsh-reading
    maxImportBytes: 209715200
```

改完重启。

## 已知限制

PDF 只读文字版，表格、分栏、公式会退化成流水文字。扫描件读不了，加密 PDF 打不开。

MOBI 的复杂排版没还原，个别书段落顺序可能不完美。加密 EPUB 打不开，会报错不会白屏。

竖排和 RTL 能读，跨页选区的高亮会降级成整段。

没有全文搜索、没有朗读、没有阅读统计。

单用户，没有账号，也就没有共享书库。跨端同步还没做，数据只在本机，自己备份 `~/.dsh-reading/`。

## 开发

```
npm install --no-save --ignore-scripts jsdom@30 ajv@8
node golden/run.mjs
node test/run.mjs
node client/build.mjs
npm run verify
```

改界面后要在 DSH 里实际点一遍。node 测试只覆盖逻辑和产物形状，布局和滚动靠眼睛。
