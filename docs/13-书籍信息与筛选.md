# 13 · 书籍信息与筛选

> 状态：已实现（`0.5.1`）。和 [`docs/08`](08-格式支持-TXT与MOBI.md)、[`docs/11`](11-格式支持-PDF.md)、
> [`docs/12`](12-找书与网络导入.md) 同一个系列：前三篇讲「怎么拿到书、怎么读」，
> 这篇讲**读完一本之后，你怎么在几十本里再找到它**。

---

## 一、结论先说

| 你想做的事 | 怎么做 | 落点 |
|---|---|---|
| 改书名 / 作者 / 简介 | 对着卡片**右键**，或点卡片右上角 `✎` | `meta.json` |
| 给书分类、归到一个系列 | 同上，编辑弹窗里填「分类」「系列」 | `meta.json` |
| 打标签（可多个） | 同上，标签用顿号、逗号或空格分隔 | `meta.json` |
| 标成「珍藏」 | 同上，勾「加入我的珍藏」 | `meta.json` 的 `favorite` |
| 换封面 | 同上，选图后保存 | 覆盖 `cover.*`，`coverVersion` +1 |
| 只看珍藏 / 某个作者 / 某个系列 / 某个标签 | 书架左上角两级下拉 | 纯前端筛选，不动数据 |

右键和 `✎` 是同一个入口：右键更符合「对着这本书操作」的直觉，`✎` 更显眼。
两个都能开同一个弹窗。

---

## 二、字段与上限

校验在宿主侧（`lib/store.js` 的 `updateMeta`），前端先在本地挡一遍，免得等一趟网络
才知道书名是空的。

| 字段 | 上限 | 空值行为 |
|---|---|---|
| 书名 `title` | 120 字 | 不许为空（必须有一行能显示） |
| 作者 `author` | 80 字 | 允许为空 |
| 简介 `description` | 2000 字 | 清空即**删除**该字段 |
| 分类 `category` | 40 字 | 清空即删除 |
| 系列 `series` | 80 字 | 清空即删除 |
| 标签 `tags` | 最多 12 个，每个 ≤24 字 | 全部删掉即删除该字段 |
| 珍藏 `favorite` | 布尔 | 取消勾选即删除 |

「空 = 删除字段」而不是「空 = 存一个空字符串」，是为了让 `meta.json` 保持干净：
老版本读进来不会看到一堆 `""`，导出时也不会带一排空键。

标签会去重、去掉两端空白、丢掉空项，顺序按你写的顺序保留。

## 三、筛选怎么工作

书架左上角是两级下拉：

1. **先选按什么筛**：全部书籍 / 我的珍藏 / 按系列 / 按作者 / 按分类 / 按标签；
2. **再选具体值**：第二级下拉的选项来自当前书架里真实存在过的值（去重、按拼音排序）。

三条约定：

- 选「按作者」但第二级还是「全部」时，**不筛**（显示全部）。这是故意的：如果这时
  就筛成「作者为空的那些书」，用户会以为书架丢书了。
- 「我的珍藏」不需要第二个参数，一步到位。
- 筛选是**纯前端**的，刷新页面回到「全部书籍」——不记忆上次的筛选条件。
  理由：书架是「找书的地方」，下次进来大概率是要看全部，而不是回到上次那个狭窄视图。

书架有书但当前筛选下没有结果时，显示「『按标签』下面还没有书。」加一个「看全部书籍」
按钮，而不是复用空书架那套「导入第一本书」的引导——那是两件不同的事。

纯函数在 `client/src/shelf.js` 导出：`filterBooks(books, kind, value)` 与
`facetValues(books, kind)`，测试在 `test/shelf_ui_test.mjs`（不渲染 DOM，只钉数据判定）。

## 四、数据落在哪

全部在每本书自己的 `meta.json` 里，没有额外的索引文件、没有数据库：

```
<书库>/<书名哈希前16位>/
  meta.json          ← title / author / description / category / series / tags / favorite
  cover.jpg          ← 有封面才有；coverVersion 记在 meta.json
  progress.json
  annotations.jsonl
```

`listShelf` 把这些字段一并返回（缺字段时给空值），所以书架一次请求就能把筛选下拉
需要的信息拿全，不用为每本书再问一次。

0.5.0 及更早导入的书没有这些字段：`listShelf` 一律补空值，界面上表现为「未分类」，
不会因为缺字段而崩或挡住筛选。

## 五、做不到的

诚实列在这里，免得以为是 bug：

- **没有批量操作**。改十本书的分类要点十次。
- **标签不能自动补全**。第二级下拉会列出已有标签，但填的时候是自由文本。
- **筛选条件不持久化**（刷新回到全部）。
- **没有「最近添加」「未读」这类智能列表**，只有上面五个维度。
- **简介只在编辑弹窗里可见**，书架卡片和阅读器里都还没有展示它的位置。
