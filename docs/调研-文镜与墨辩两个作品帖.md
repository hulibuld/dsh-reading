## 一、文镜 WenJing —— 读书拆解台

**帖子**：https://tianchi.aliyun.com/forum/post/1102806 ｜ **作品**：https://wenjing-uggayt1d6lq.qoder.zone
**作者**：计算机专业大三，独立完成。

### 一句话

把一本书或一份 PPT 丢进浏览器，几分钟内还你一张人物关系图谱、几条主题线、一条情感曲线，以及可以逐章精读的交互导读。

### 面向谁

正在读长篇小说、文史类作品或翻课件的大学生——要写读书报告、做分享、复习备考，但没时间做笔记，也不想把整本书上传到陌生服务器。

### 三条设计原则（原文）

1. **原文不上传**：文件在浏览器内存里解析，平台只保存拆分后的章节文本与分析结果；
2. **证据可回溯**：摘要、主题、引文全部标注出处章节，点开就能回到原文；
3. **按文体读**：小说看人物与关系，文论看逐则条目，PPT 看逐页要点。

### 它做了哪些具体的东西

| 模块 | 做法 |
| --- | --- |
| 人物关系图谱 | 可拖动节点、悬停看共现次数与对话语气；另有「人物榜」「关系明细」 |
| 主题线 | TF-IDF 关键词 + Jaccard 聚类，主题必须带**强度与覆盖率** |
| 情感曲线 | 情感词典**逐章**打分，以 0 为基线，正负一眼可辨 |
| 摘要 | **抽取式**：坚持抽原句、不改写 |
| 文论模式 | 切分从「章 / 节」扩展到「则」，无人物图谱，突出主题与引文 |
| 解析引擎 | Web Worker 里跑：`Intl.Segmenter` 分词、TF-IDF、Jaccard、情感词典、抽取摘要 |
| 文体识别 | 上传时自动识别：小说 / 散文 / 文论 / 演示文稿 |

### 它踩过、并且写出来的坑（这段最有价值）

- 第一版把「古代」「明月」「余谓」当成人名，把「辛弃疾」截成「辛弃」。最后改成三层规则：**姓氏窗口 + 分词边界校验 + 通用词词频剔除**；
- 无姓氏音译名（悉达多、迦摩罗）靠**引语模式**（说 / 道 / 问 / 答 / 曰）识别；
- 别名合并：小悉达 → 小悉达多，否则图会裂成两半；
- 判定「这本书该不该出人物图」用**文类**，不是硬抽。

### 边界（自己声明的）

支持 PDF / EPUB / TXT / PPTX，单文件 ≤ 30 MB；扫描版 PDF（无文字层）无法分析。

## 二、墨辩 Ink & Idea —— 浏览器里的文学辩论场

**帖子**：https://tianchi.aliyun.com/forum/post/1103062 ｜ **作品**：https://ink-and-idea-21m1bgr35mo.qoder.zone
**作者**：安徽工业大学人工智能专业大一，个人参赛。

### 一句话

给喜欢读书又喜欢争论的人，一个打开就能上场、三分钟能读完一轮的文学辩论场。

### 主循环

读今天的命题句 → 写下自己的一段理解 → 站「正方」或「反方」发言 → 看两边阵营支持度此消彼长 → 个人中心看段位与当日热榜。

### 起点（作者原话）

> 现在的读书类产品要么把阅读变成打卡，要么把讨论变成点赞数比赛。而真正的文学讨论是**有阵营、有代价、有回合**的——你得先选一边，然后为这一边说出一句站得住的话。

### 技术形态

**纯静态，无后端**：账号、段位、点赞全部存在访客自己的浏览器里（localStorage + PBKDF2-SHA256 15 万次迭代 + 每账号独立随机盐）。零外网请求，离线可用。6 个页面统一注入 CSP `default-src 'self'`，零内联脚本。

### 它自己抓出来的两个真实缺陷（工程上值得看）

1. `toHex()` 写成 `byte + '0'` 的字符串拼接 → 每个随机字节被折叠成 10 种取值 → 16 字节盐的实际熵从 128 位掉到约 53 位。**本地往返测试是绿的**，因为「生成」和「比对」走同一条有损路径，自我一致。修复后写了 86 条确定性断言，并把 3 个已知缺陷分别改回去做变异测试，证明测试不是自我表扬；
2. 为帖子拍首页截图时，发现卡片上出现「张三 分享」「李四 分享」——种子数据的占位名。**截图这一步不只是产出材料，它替作者做了一轮人工验收。**

### 它写进帖子的「诚实项」

- 首页「AI 洞见」是内置示例文案，不是实时模型输出；
- 没有后端，身份、段位、点赞都可被本机篡改，这是静态架构的固有边界，已写进站内 `security.html`；
- 每位访客看到独立数据，不是共享实时社区。

## 三、两句总结

- **文镜**：把「读完之后脑子里那团模糊的印象」变成**可以点开、拖动、对照**的东西。它补的是「图」这一层——图要能交互、要带量化轴、要按文体变。
- **墨辩**：把「读完之后不肯表态」变成**先选边、再说一句站得住的话**。它补的是「判断」这一层——判断要有阵营、有代价、有回合。

两个作品缺的正好是对方有的：文镜有图没观点，墨辩有观点没图。
