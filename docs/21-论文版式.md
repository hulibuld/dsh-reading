# 论文版式（0.10.0）

PDF 现在有两条排版路线，导入时由**用户**选，插件不替他决定。

| | 普通书 | 论文 |
|---|---|---|
| 怎么进来 | 默认 | 导入后弹出询问，点「按论文排版」 |
| 分章依据 | 页段（每 8 页）或正文里认出的章标题 | 一级/二级标题、参考文献 |
| 首页 | 直接进正文 | 标题、作者、单位、摘要、关键词 |
| 目录 | 常常为空（显示「这本书没有目录」） | 每个小节一条，点得动 |
| 参考文献 | 混在正文里 | 单独一章 |

## 为什么不让插件自己判断

一本书开头出现「摘要」两个字，可能只是某一章叫摘要；反过来，中文期刊论文开头常先有两行刊名、ISSN、收稿日期，标题和摘要被挤到第三行以后。这两种情况凭字符猜都猜错，所以改成：**只报告线索，让人点一下**。

线索只扫首页开头几段（默认 6 段，覆盖「刊名 + ISSN + 标题 + 作者 + 摘要 + 关键词」这种典型排布），不读全文——读完全书也不会让判断更准，只会让导入变慢。

线索长这样（`meta.pdfPaperHint`）：

```json
{
  "looksLikePaper": true,
  "title": "文学评论 2023 年第 2 期",
  "sample": ["文学评论 2023 年第 2 期", "ISSN 0511-4683", "论鲁迅《祝福》中的叙述时间", "钱禹舟", "摘要：本文讨论叙述时间。", "关键词：鲁迅；祝福"],
  "hasAbstract": true,
  "hasKeywords": true,
  "reason": "开头几行里「摘要」和「关键词」都在"
}
```

`reason` 直接念给用户听，`sample` 让他自己确认第一行是不是真标题——很多期刊 PDF 第一行是刊名，不是标题，这一点必须让他看见。

## 选了之后发生什么

1. 界面 `book.layout`（`{ bookHash, layout: 'paper' | 'book' }`）。
2. 宿主把 `book.pdf` 按目标版式**真排一遍**。排不出来（找不到摘要、关键词、参考文献）就报 `E_PAPER_LAYOUT`，不动 meta——宁可让人再点一次，也不要写下一个「标记是论文、打开还是书」的自相矛盾状态。
3. 排得出来就写回 `meta.spine` / `meta.toc` / `meta.pdfLayout`，清解析缓存，**删掉 progress.json**。

第 3 步删进度是有意的：版式变了，章号、页码全变，留着旧进度会让人停在「第 17 页」这种新书里不存在的位置。批注也按同样道理说明：CFI 指向旧章节的旧节点，换版式后可能对不上，界面上写了这句。

之后每次打开这本书，`store.getParsed` 都会读 `meta.pdfLayout` 并把它传给解析器，所以不会出现「翻到下一章又变回普通书」的情况。

## 版式细节

标题居中加粗 1.55em，作者居中，单位小一号居中，摘要与关键词做成带左侧竖线的浅底块，关键词拆成小标签。正文段落首行缩进两字、两端对齐、行高 1.95。参考文献用悬挂缩进（`text-indent: -1.6em`），条目各占一行。

所有尺寸用 `em`，跟着阅读器的字号设置一起缩放——论文正文要比小说小一点才像论文，但用户调大字号时不能纹丝不动。

## 认得出什么、认不出什么

认：

- `摘要：` / `Abstract：`，中文全角冒号、半角冒号、无冒号三种写法
- `关键词：` / `关键字：` / `Key words：`
- 一级标题：`一、` `二、` ……；二级标题：`（一）` `(1)`
- 英文论文的 `1 Introduction` / `2.1 Method`
- 结构词：引言、绪论、结语、结论、余论、附录、注释、致谢
- `参考文献` / `引用文献` / `References` / `Bibliography`

认不出（这些会原样混进正文，不报错）：

- 双栏排版。两栏文字在同一水平线上会被当成同一行，读出来是栏 A 半句接栏 B 半句。中文期刊单栏居多，先按单栏做。
- 表格里的文字。表格线不参与抽取，单元格文字会连着排。
- 脚注与正文的区分。脚注常被排到页面底部，抽取时落到该页末段。
- 公式。公式大多是字体里的符号，抽出来是乱码或空白；这一版没有渲染器，取不出图。
- 页眉页脚。纯数字（页码）会被丢掉，带文字的页眉会留下。

## 测试

`test/paper_test.mjs` 六组：判据、标题判据、结构抽取、关键词拆分、HTML 产物、接进 `parsePdf` 的两条路（默认书 / 选了论文），外加「期刊页眉在前也认得出」和「硬排论文认不出结构要报错」。

`test/e2e_local_test.mjs` 里有一条真链路：导入论文 PDF → 默认按书排、`pdfPaperHint.looksLikePaper === true` → `book.layout paper` → 目录里出现「参考文献」、首页带 `pp-title` → 改回 `book` → 版式传 `weird` 时 400。
