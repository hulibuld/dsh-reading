# 14 · 书内搜索与标注交互（0.6.0）

本轮解决四件事：**找得到**（书内搜索、笔记搜索、问答滚动）、**看得清**（当前章坐标、
主题化高亮）、**点得准**（页底热区、划词小窗、划线与翻页热区的层级）、**不乱跑**
（跨栏划线越界裁剪）。

## 1. 书内搜索

**为什么服务器侧扫**：正文在磁盘上，浏览器只拿到「当前这一章」的 HTML。要搜全书就得
把整本书灌进浏览器——重排书动辄几百章、几 MB，手机端直接崩。宿主逐章取文本、逐章丢，
内存只要一章。

接口：`book.search`（POST，`{ bookHash, query, limit }`）→

```json
{ "query": "晨跑", "total": 37, "truncated": true, "scannedChapters": 214,
  "hits": [{ "spineIndex": 12, "chapterLabel": "第三章 夜晚", "percent": 0.42,
             "snippet": "…假日里他也会晨跑，只是路线换成了公园。…",
             "hitOffset": 812, "query": "晨跑" }] }
```

三条硬约定：

1. **`percent` 而不是字符偏移**：客户端是分页模型，`percent` 可以直接换算成
   「这一章的第几页」，而字符偏移还得走一遍 CFI 反解。
2. **最多 2000 处命中、最多回 200 条**：单字「的」在百万字书里能命中几万次，
   用户要的是「这本书里有」，不是逐条列出来。截断时 `truncated: true`，界面写「结果已截断」。
3. **空词不扫，超长词报错**（`E_SEARCH_TOO_LONG`，>60 字）。静默截断比报错更糟。

客户端 `book.search` → `SearchPanel`（`client/src/search.js`）。跳转走
`jumpToSpine(hit.spineIndex, { percent: hit.percent, flash: true })`。

快捷键：Ctrl/⌘+F。**为什么接管浏览器自带的页内查找**：它只能查「当前这一章的当前页」，
用户以为搜的是全书，搜不到就以为书里没有。

## 2. 页底翻页热区

正文底部左右各一块 `34% × 18%` 的透明热区，中间 `32%` 留白给划词。
两侧 26px 的窄条在手机上够不到；盖满底边又会和「拖选到最后一行」打架，所以留中间。

层级：`.dr-hl { z-index: 2 }` 高于 `.dr-turn-zone`（1），否则正文最后两行的划线被热区吃掉点击。

## 3. 主题化高亮

五色各有明暗两套变量（`--dsh-reading-hl-*`），夜间主题改「深底亮字」。实现要点：

- `reader.js` 在 `.dr-reader` 上写 `data-theme`（`light` / `sepia` / `green` / `dark`）；
- `annotate.js` 给高亮盒子补 `dr-hl-<color>` 类名；
- CSS 用 `!important` 压过内联 `background` / `boxShadow`（内联优先级高，这是唯一可行手法）。

## 4. 划线越界裁剪

跨栏文字的 `getClientRects()` 会给出「从本栏末尾延伸到下一栏」的矩形，不裁就画到正文外、
压住侧栏和翻页热区。`computeRects()` 现在按 `frameBox` 的矩形裁剪，完全在页外的段直接丢弃。

**量不到页尺寸就不裁**：假 DOM（单元测试）或尚未上屏时 `frameBox` 宽高为 0，
硬裁会把所有盒子裁成 0 个——那等于「什么都没画」，比画到页外更糟。

## 5. 笔记与问答面板

- 笔记：搜索框（文字 / 笔记 / 章节名）+ 类型 chip（全部 / 划线 / 笔记 / 书签）+
  「按章节 / 按时间」分组切换；分组行由 `groupRows()` 产出一维数组，渲染侧一次 map 即可。
- 问答：滚轮只滚列表（`preventDefault` + `stopPropagation` 阻止冒泡成翻书），
  Shift 加速 2.5 倍，右下角另给 ↑ / ↓（一次滚一屏的 80%，不写死像素）。

## 6. 尺寸不再写死像素

| 位置 | 旧 | 新 |
| --- | --- | --- |
| 左右翻页条 | `26px` | `clamp(18px, 2.4%, 40px)` |
| 侧栏 | `244px` | `clamp(248px, 26%, 380px)`（窄屏 `78%`） |
| 栏间距 | `48px` | 视口宽的 `6.8%`，上下限 `28–72px` |
| 阅读区左右内边距 | 无 | `clamp(8px, 1.2%, 24px)` |
