## 1. 零运行时依赖（已定，不许改）

`package.json` 的 `dependencies` **必须为空对象**。理由：

1. `dsh plugin add` 从 git 装包时要跑 `prepare`，带原生依赖必然踩编译；
2. 本机 profile 目录**禁止**跑 `pnpm add/install`（会重装整棵依赖树，已经出过一次事故）；
3. 我们需要的外部功能只有三件，都能自己写：
   - ZIP 解压 → `node:zlib` 的 `inflateRawSync`（lib/zip.js）
   - XML 解析 → 自己写的严格子集解析器（lib/xml.js）
   - CFI 编解码 → **vendor** foliate-js 的 `epubcfi.js`（MIT，已放 `client/vendor/epubcfi.foliate.js`）

`devDependencies` 允许：`jsdom`（只用于 golden 与单测的 DOM）。**不得**进 `dependencies`。

`peerDependencies` 允许且仅允许 `@deepseek-ai/schemastery`（宿主提供）。**不得**把 `@deepseek-ai/dsh-*` 写进 `dependencies`。

## 3. 宿主侧契约

### 3.1 入口 `index.js`

```js
import z from '@deepseek-ai/schemastery'

export const name = 'dsh-reading'
export const inject = ['webServer']          // 缺 webServer 就明确失败，不做半死状态
export const Config = z.object({
  libraryDir: z.string().default(''),        // 空 = ~/.dsh-reading
  maxImportBytes: z.number().default(200 * 1024 * 1024),
})
export function apply(ctx, config) { /* 注册路由 */ }
```

规则：
- 配置**必须**是 schemastery schema（普通对象会抛 `Cannot read properties of undefined (reading 'validate')`）。
- 所有路由注册走 `ctx.webServer.register(...)` 返回的 disposer，包在 `ctx.effect()` 里。
- `apply` 里不许 `await` 顶层 IO；慢操作放请求处理内。
- 抛错一律 `console.warn('[dsh-reading] ...')` 且只抛一次，不刷屏。

### 3.2 书库布局（本地，与将来 WebDAV 同构）

```
<libraryDir>/dsh-reading/
├── settings.json                      # 阅读偏好（字号/主题/栏宽），非敏感
└── books/<bookHash>/
    ├── book.epub                      # 原文件（本地必存；将来同步默认不同步）
    ├── meta.json
    ├── progress.json
    ├── annotations.jsonl
    ├── qa.jsonl
    ├── quarantine.jsonl
    └── history/                       # 被覆盖前的旧文件，保留 20 份
```

`bookHash` = `sha256(epub 字节)` 的**小写 hex 前 16 位**（与 docs/02 一致：目录名 16 位，`meta.bookHash` 存 64 位全串）。

### 3.3 HTTP 接口

统一前缀 `/api/dsh-reading`，注册为 **`{ kind: 'prefix', path: '/api/dsh-reading' }` 单条路由**，
内部按 `method + path` 分派。**不得**注册 `/plugins/*` 前缀（那是 client-modules 的地盘，会撞）。

写操作走 `POST /api/dsh-reading/<method>`，body 是 JSON，返回 `{ ok: true, value }` 或
`{ ok: false, error: { code, message } }`（HTTP 状态码：成功 200，业务失败 400，内部错误 500）。

| method | 入参 | 返回 `value` |
|---|---|---|
| `device.info` | — | `{ deviceId }` |
| `shelf.list` | — | `{ books: [{ bookHash, title, author, percent, updatedAt, coverUrl|null }] }` |
| `shelf.import` | `{ filename, dataBase64 }` | `{ bookHash, meta }` |
| `shelf.remove` | `{ bookHash }` | `{ removed: true }` |
| `book.meta` | `{ bookHash }` | `meta`（§4.1） |
| `book.toc` | `{ bookHash }` | `{ toc: [{ label, href, spineIndex, depth }] }` |
| `book.spine` | `{ bookHash }` | `{ spine: [{ href, idref, index }] }` |
| `progress.get` | `{ bookHash }` | `progress` 或 `null` |
| `progress.put` | `{ bookHash, cfi, cfiStart, chapterHref, percent }` | `{ saved: true }` |
| `ann.list` | `{ bookHash }` | `{ records: [...] }`（已过滤 `deleted:true`） |
| `ann.put` | `{ bookHash, record }` | `{ record }`（服务端补 `updatedAt`） |
| `ann.delete` | `{ bookHash, id }` | `{ deleted: true }`（写墓碑，不删行） |
| `settings.get` | — | `{ fontSize, lineHeight, theme, columns, fontFamily }` |
| `settings.put` | 同上任意子集 | 合并后的 settings |
| `quarantine.list` | `{ bookHash }` | `{ entries: [...] }` |

静态资源走 **GET**（同一前缀）：

| path | 说明 |
|---|---|
| `GET /api/dsh-reading/chapter?book=<hash>&href=<urlencoded>` | 章节 XHTML（§3.4） |
| `GET /api/dsh-reading/asset?book=<hash>&href=<urlencoded>` | 章节内引用的图片/CSS/字体 |
| `GET /api/dsh-reading/cover?book=<hash>` | 封面图（取 OPF `cover-image`，没有就 404） |

路由体里必须拒绝路径穿越：`href` 解码后不许含 `..`、不许以 `/` 开头，拼完 `path.resolve` 后必须仍在前缀内。

### 3.4 章节响应头（这决定 CFI 能不能算对）

```
Content-Type: application/xhtml+xml; charset=utf-8
Content-Security-Policy: default-src 'none'; img-src 'self' data: blob:; style-src 'unsafe-inline' 'self'; font-src 'self' data:; script-src 'none'
X-Content-Type-Options: nosniff
Cache-Control: private, max-age=300
```

- 必须以 `application/xhtml+xml` 提供：EPUB 内容文档是 well-formed XHTML，用 XML 模式解析才与规范一致，CFI 才可跨端复现。
- `script-src 'none'` 是铁律 4/§3.4 第 5 条：书内脚本绝不许跑。
- 章节 HTML 必须**原样输出**：不许重排属性、不许美化缩进、不许插入任何元素。允许的唯一改动是把相对 `src`/`href` 改写成 `/api/dsh-reading/asset?book=…&href=…`（**只改属性值，不增删节点**）。

### 3.5 `lib/epub.js` 导出

```js
export async function parseEpub(filePath) → {
  meta: { schema, bookHash, title, author, format:'epub', fileSize, spine:[{href,idref}], converterVersion, createdAt, updatedAt, deviceId },
  toc:  [{ label, href, spineIndex, depth }],
  chapterHtml(href) → Promise<string|null>,   // 原样 XHTML 文本
  assetBytes(href)  → Promise<{ bytes:Buffer, mediaType:string }|null>,
  coverHref → string|null,
}
```

解析要求：
- 只支持 ZIP 存储/`deflate`；`deflate64`、加密 EPUB（`META-INF/encryption.xml` 有 `<EncryptedData>`）→ 抛 `E_EPUB_ENCRYPTED`。
- 必须有 `META-INF/container.xml` → 取第一个 `rootfile@full-path` → 解析 OPF。
- 解压总大小上限 512 MB，单文件上限 64 MB，超限抛 `E_EPUB_TOO_BIG`（防压缩炸弹）。
- 条目数上限 20000（防炸弹）。
- 书名/作者取 OPF `dc:title` / `dc:creator`（`dc:creator` 可能多个，取第一个非空），缺失回退文件名。
- spine 只取 `itemref` 且对应 manifest `media-type` 为 `application/xhtml+xml`（或 `text/html`）的项。

### 3.6 `lib/xml.js` 导出

```js
export function parseXml(text) → Node
// Node = { type:'element', name, attrs:Record<string,string>, children:Node[] }
//      | { type:'text', value:string }
//      | { type:'cdata', value:string }
export function findAll(node, pred) → Node[]
export function textOf(node) → string          // 递归取文本（不含空白压缩）
export function attr(node, name) → string|undefined
```

硬要求：
- 处理注释 `<!-- -->`、`<?xml ?>`、`<!DOCTYPE ...>`、CDATA、命名空间前缀（`dc:title` 当作名字 `dc:title` 原样保留）。
- **不做**外部实体、**不做** DTD 展开（安全面）。
- 预定义实体 `&amp; &lt; &gt; &quot; &apos;` + 数字实体 `&#nn;` / `&#xhh;`。
- 遇到不闭合标签必须抛错（`E_XML_MALFORMED`），不许「尽力而为」——静默修好会让 CFI 指向错误位置。

### 3.7 `lib/zip.js` 导出

```js
export function readZip(buf) → { entries: [{ name, size, compressedSize, method, read():Buffer }], has(name), get(name):Buffer }
export function writeZip(entries: [{name, data:Buffer}]) → Buffer   // 仅 store，测试与 fixture 用
```

要正确处理：中央目录偏移、`general purpose bit 3`（data descriptor，size 在 descriptor 里）、Zip64（可拒绝，抛 `E_ZIP64` 并说明不支持）。

## 4. 数据契约（与 docs/02 一致，此处只补三处落地细节）

### 4.1 `meta.json`

```json
{ "schema":"dsh-reading/1","bookHash":"<64 hex>","title":"…","author":"…",
  "format":"epub","fileSize":1234567,
  "spine":[{"index":0,"href":"text/ch1.xhtml","idref":"ch1","mediaType":"application/xhtml+xml"}],
  "converterVersion":"epub/1",
  "createdAt":"…","updatedAt":"…","deviceId":"…" }
```

**`spine[].index` 必填**（`schema/contract.schema.json` §`$defs/meta.spine.items.required` = `["index","href"]`）。
`index` 是 0-based 的 spine 序号，与 `client/src/cfi.js` 的 `spineIndexFromCfi()` 返回值同一口径——
客户端不解析 OPF，就靠这个字段把「章节 href」映射回「CFI 前缀里的 `/6/<2*(index+1)>`」。
`meta.fileSize`/`updatedAt`/`deviceId` 也已补进 schema（只加不删，其它字段原样保留）。

### 4.2 指纹算法（两端必须一字不差）

```
head = 文本前 48 个 UTF-16 code unit
tail = 文本后 32 个 UTF-16 code unit
len  = 文本 UTF-16 code unit 长度
hash = sha256(文本的 UTF-8 字节) 的小写 hex
```

`tail` 取的是**最后 32 个 code unit**，不是「除 head 外的后 32 个」；文本短于 48 时 `head` 与 `tail` 会重叠，这是允许的。

比对（三态）：

| 条件 | 结果 |
|---|---|
| head/tail/len/hash 全等 | `ok` |
| head/tail/len 全等、hash 不等 | `drifted`（降级渲染，`anchorStatus:"drifted"`） |
| 其余 | `fail` → 隔离，`reason = "fingerprint_drift"` |

### 4.3 t=0 的记录信封

所有写入函数统一走 `client/src/contract.js` 的 `makeRecord(type, fields)`：
- `id` 用 ULID（26 位 Crockford Base32，同一毫秒内自增单调）
- `createdAt`/`updatedAt` = `new Date().toISOString()`（**天然带毫秒与 Z**，不要自己拼）
- `deviceId` 由宿主 `device.info` 给，缓存在 localStorage
- `schema` 恒为 `"dsh-reading/1"`

## 5. 客户端契约

### 5.1 打包方式（无打包器）

`client.js` 必须是**自包含 CJS**，形状固定：

```js
window.__ModuleLoader__.load({
  id: "dsh-reading",
  factory: (require) => {
    var module = { exports: {} }; var exports = module.exports;
    /* ---- 由 build.mjs 拼进来的 src/*.mjs 正文（去掉 import/export 语法） ---- */
    exports.apply = apply;
    exports.inject = inject;
    return module.exports;
  }
});
```

`build.mjs` 做法（照抄 `dsh-ai-waifu/scripts/build-client.mjs` 的**思路**，但更简单）：

1. 按**写死的顺序**读 `client/src/*.mjs`；
2. 校验每个文件：不许有 `import` 语句（`cfi.js` 是唯一例外，它的 import 会被替换成 vendor 内容）；
3. 用行扫描状态机剥掉 `export ` 与 `import ... from '...'`，不许用裸正则；
4. `cfi.js` 的 `import * as CFI from '../vendor/epubcfi.foliate.js'` 那一行替换为 vendor 文件正文（vendor 是 ESM，同样去 `export `）；
5. 产物末尾断言：`export ` 出现 0 次、能被 `new Function` 求值、`window.__ModuleLoader__.load(` 恰好 1 次；
6. `--check` 模式：与磁盘上的 `client.js` 逐字节比对，不一致退出码 1（CI 用）。

模块顺序：`sha256 → cfi → contract → api → style → shelf → toc → reader → annotate → app`。

### 5.2 `client/src/cfi.js`（★ 锚点核心，唯一碰 vendor 的文件）

```js
// 注入节点识别
export const INJECTED_ATTR = 'data-dsh-reading-injected'
export function makeFilter(win) → (node) => number
//   命中 INJECTED_ATTR → win.NodeFilter.FILTER_REJECT（v1.1 从 SKIP 改，见 docs/07）
//   其余 → FILTER_ACCEPT
//   实现必须同时兼容 node.hasAttribute 与 (node.getAttribute && node.getAttribute(name)!=null)

// 生成：range → 完整 CFI（含 spine 前缀）
export function fromRange(win, range, spine) → string
//   spine = { index: number, idref?: string }   // 0-based
//   返回 epubcfi(/6/<2*(index+1)>[idref]!/…)

// 解析：完整 CFI + 当前 doc → Range
export function toRange(win, doc, cfi) → Range
//   内部先 parse，再校验 L1/L2，最后 toRange(doc, parts, filter)
//   任何一步失败抛 { name:'CfiError', code, detail }，不返回 null

// 三层校验
export function validate(win, doc, cfi, expectedFingerprint) → { ok:boolean, level:'L1'|'L2'|'L3', code?:string }
//   失败码枚举严格用：cfi_parse_failed / cfi_resolve_failed / cfi_range_inverted /
//   cfi_cross_document / cfi_collapsed_highlight / cfi_offset_out_of_bounds /
//   cfi_prefix_mismatch / fingerprint_drift

// 工具
export function spineIndexFromCfi(cfi) → number        // parts.at(-1).at(-1).index/2 - 1
export function chapterHrefFromCfi(cfi) → string|null  // 取 '!' 左半段最后一段的 id
export function joinCfi(prefix, localRange) → string   // 组装并校验恰一个 '!'
export function splitCfi(cfi) → { prefix, local }
export function textOfRange(range) → string
```

实现硬规则（**违反即视为锚点污染**，审查按条打回）：

1. **不暴露无 filter 的调用路径**。`toRange`/`fromRange` 内部一律带 filter，导出签名里没有 filter 参数。
2. **序列化自己写**（`partsToString`）：只保留**每条 local path 最后一段**的 `id`，中间段 `id` 一律丢弃。这对应 docs/03 §四的实测。
3. `fromRange` 遇到 `range.collapsed === true` 且调用方要 highlight 时，由**上层**判错；`fromRange` 本身返回折叠 CFI（无逗号形态），不许把折叠 CFI 当区间存。
4. `validate` 的 L2 必须显式检查：
   - `startOffset > endOffset` 且同节点 → `cfi_range_inverted`
   - `!` 左半段推导出的 href 与记录里的 `chapterHref` 不符 → `cfi_prefix_mismatch`（**不是**直接失败：按 docs/01 §3.3，以 `chapterHref` 为准重建前缀后重试一次，仍不符才失败）
   - 解析出的 Range 落在 `#document` 或 `documentElement` 上（跨文档/越界静默失败的特征）→ `cfi_cross_document`
   - `range.collapsed` 而记录是 highlight → `cfi_collapsed_highlight`
5. L3 只在有 `expectedFingerprint` 时执行；比对走 §4.2 的三态。
6. **不许 try/catch 吞异常后返回默认值**。所有失败都要带 code 抛出，由调用方决定进隔离还是提示。

### 5.3 `client/src/contract.js`

```js
export const SCHEMA = 'dsh-reading/1'
export function makeUlid(now?) → string                  // 26 位，单调
export function fingerprint(text) → { head, tail, len, hash }   // 用 sha256.js
export function compareFingerprint(a, b) → 'ok'|'drifted'|'fail'
export function makeHighlight(fields) → record
export function makeNote(fields) → record
export function makeBookmark(fields) → record
export function makeQa(fields) → record
export function makeQuarantine(fields) → record
export function validateRecord(record) → { ok, errors:[{field,message}] }
```

`makeHighlight` 等构造器必须**硬校验必填字段**：缺 `cfi`/`chapterHref`/`textExcerpt`/`textFingerprint` 直接 throw，不降级（铁律 5 的落地点）。

`validateRecord` 是 `schema/contract.schema.json` 的手写同构版：**不引 ajv**（浏览器半零依赖），但必须与 schema 字段表一一对应；`test/schema_parity_test.mjs` 用 ajv（devDependency）交叉验证两者判定一致。

### 5.4 `client/src/reader.js`（M1 的核心）

分页方案（已定，不许改成整章滚动）：

1. `<iframe sandbox="allow-same-origin" src="/api/dsh-reading/chapter?book=…&href=…">`；
2. 等 `load` 后，往 `contentDocument` 注入**一个** `<style data-dsh-reading-injected>`（CSS 分栏：`html,body{height:100%;margin:0}` + `body{columns:<W>px; column-gap:<G>px; height:100%}`）；
   - 这是唯一允许注入的节点，且必须带 `data-dsh-reading-injected`，filter 会跳过它；
   - 注入 `<style>` 不改变元素树结构（`<head>` 里多一个元素不影响 `body` 内的 CFI 索引），**但**为保险起见仍打标记。
3. 分页：`scrollWidth / (clientWidth + gap)` 算总页数；翻页 = 改 `body.style.transform = translateX(-page*(W+G)px)`。
4. 「当前页首字符的 CFI」= 用 `caretRangeFromPoint` 拿到视口左上角第一个字符的 Range → `fromRange`。
5. 进度：`percent = 本章内页序 / 总页数`，再按 spine 权重折算全书；**存的是 CFI + percent 两份**，恢复时优先用 CFI，CFI 校验失败才退 percent 并进 `anchorStatus:"drifted"`。
6. 恢复位置：把 CFI 解析成 Range，量出它的 `getBoundingClientRect().left`，反算页序。

**不许**在 `contentDocument` 里做这些事：包裹 `<span>`、改 `innerHTML`、插入脚本、`document.body.appendChild` 用于高亮的节点。高亮只走 `annotate.js` 的覆盖层。

### 5.5 覆盖层（annotate.js）

- 覆盖层是**父窗口**里的一层绝对定位 `<div>`，坐标系对准 iframe 的 `contentWindow`；
- 每条高亮：`range.getClientRects()` → 若干矩形；矩形坐标加上 `iframe.getBoundingClientRect()` 的偏移，再按当前页 `translateX` 反算；
- 颜色五档：`yellow/green/blue/pink/purple`，用主题 token 的派生色（`color-mix` 不用；直接给固定 rgba，避免在浅色主题下发灰）；
- 选区菜单：父窗口监听 `iframe.contentDocument` 的 `selectionchange`（`allow-same-origin` 下可直接挂），菜单位于父窗口，避免被 iframe 裁切。

### 5.6 注册进 DSH（app.js 的 `apply`）

照 `dsh-lifecard` 的双入口模式（**已验证可用**）：


## 6. golden 向量规范

`golden/vectors.json`：

```json
{ "version": 1,
  "vectors": [
    { "id": "nested-inline-001", "fixture": "nested-inline", "chapterHref": "text/ch1.xhtml",
      "spineIndex": 0, "idref": "ch1",
      "startPath": "/4/2/2/1", "startOffset": 3,
      "endPath": "/4/2/2/1", "endOffset": 8,
      "expectedCfi": "epubcfi(/6/2[ch1]!/4/2/2/1:3,/4/2/2/1:8)",
      "excerpt": "lo, W",
      "kind": "normal" }
  ] }
```

- `startPath`/`endPath` 是**规范化树路径**（`/4/2/2/1`），由 fixture 生成脚本写死，不靠运行时推导——这样向量本身就是独立真值。
- `kind`: `normal` | `malformed`。
- 畸形向量多一个 `expectCode`（§5.2 的 8 个码之一）。
- 至少 200 条，其中畸形 ≥ 30 条，覆盖 docs/03 §三表格里 B1–B8 全部 8 种。

`golden/run.mjs` 用 jsdom 载入 fixture 章节 HTML，按 `startPath/startOffset` 手工构造 Range，跑
`fromRange` → 与 `expectedCfi` 比 → `toRange` → 比 `excerpt` → 打 `PASS n/n`。畸形向量断言 `expectCode`。

**注意**：`golden/run.mjs` 必须能直接 `node golden/run.mjs` 跑（Node 原生 ESM + jsdom 从 devDependencies 导入）。

## 10. 已知坑（都已核过，别再踩）

1. **配置必须是 schemastery schema**，普通对象会让插件静默不激活。
2. **不要注册 `/plugins/*` 路由**：client-modules 占着 `/plugins` 前缀。
3. **不要在 profile 目录跑 `pnpm add/install`**（会重装整棵树，已造成一次事故）。
4. **iframe 必须带 `sandbox="allow-same-origin"` 且不带 `allow-scripts`**；缺 `allow-same-origin` 就拿不到 `contentDocument`，CFI 无法算。
5. **章节必须以 `application/xhtml+xml` 返回**，否则 DOM 结构与规范不一致，跨端 CFI 会错位。
6. `foliate-js` 的 `fromRange` 返回的是**局部 CFI**（无 `!` 前缀），必须自己拼 spine 前缀。
7. `parse()` 对畸形输入太宽容：起止倒置、跨文档都能「解析成功」，只能靠 L2/L3 挡。
8. `partsToNode` 只读**最后一段**的 `id`；中间段写 `id` 会让解析直接抛错。
9. `fake.toIndex(parts)` 传完整 parse 结果返回 `null`，要用 `parts.at(-1).at(-1).index/2-1`。
10. 注入节点必须打 `data-dsh-reading-injected` 且 filter 返回 `FILTER_REJECT`（v1.1 改；原先照 docs/01 用 `FILTER_SKIP`，实测生成/解析各用一套下标，见 docs/07 §F7）。
11. 所有记录写入前一律过一遍指纹；`textExcerpt` 是必填，不许为了「先跑通」把它留空。
12. 浏览器半**不许** `require('@deepseek-ai/...')`：拿不到，且会把整个 slot 搞白。
