# 构思：给 reading 插件内置一条知网检索渠道

2026-11-12。用户要求：插件能连知网、能搜论文，账号密码由用户自己配，凭据绝不能进代码或仓库。
参考了本机 `~/carsi-bridge/` 的交接文档，但**没有照搬它的做法**（它是 Python + Playwright 每天无人值守下 PDF，属于个人脚本；插件要面向所有装插件的人）。

---

## 结论先说

**能做的是「检索」，不是「下载」。**

知网有一个老版检索站，不登录、不要验证码、在 Node 里直接 POST 就能拿到结果：
标题、作者、期刊、年期、关键词、被引次数、下载次数、文献类型、网址，外加正文开头约 120 字。
期刊论文、硕士论文、博士论文、会议论文都能搜到。

拿不到的是：**完整摘要**（详情页恒定截断在 128 字）、**PDF 全文**（必须登录，登录必须真实浏览器过密码加密 + 极验）。

所以这条渠道的定位是：**帮你在知网上把该读哪几篇挑出来，然后你把 PDF 自己下下来导入书架读。** 不是替你下。

---

## 一、实测边界（都是本机真跑出来的，不是查资料）

### 能用的：`search.cnki.com.cn`（老版检索站）

| 项 | 实测结果 |
| --- | --- |
| 数据接口 | `POST https://search.cnki.com.cn/search/listresult`，`content-type: application/x-www-form-urlencoded`，返回 HTML 片段 |
| 请求体 | `Title=<词>&Order=<1-4>&page=<n>`，字段名也可以是 `Theme=` / `KeyWd=` / `Author=` / `content=` |
| 每页 | 固定 20 条，`page` 翻到 500 都有效，没发现硬上限 |
| 速度 | 0.2–1.9 秒，连续 10 次无限流 |
| 编码 | 响应头直接给 `charset=UTF-8`，不用猜 GBK |
| 不要带的 | `x-requested-with` 可带可不带；但 `POST /api/search/listresult` 那个变体**一律 504**，别碰 |

**排序 `Order` 的含义（实测验证过真的换序）：**

| 值 | 含义 | 实测特征 |
| --- | --- | --- |
| 1 | 相关度 | 默认，结果跟词最贴，但被引/下载可能都是 0（新文） |
| 2 | 发表时间降序 | 首条是最新文，被引全是 0 |
| 3 | 下载次数降序 | 首条下载 39870 |
| 4 | 被引次数降序 | 前五 4569/3019/1984/1748/1375，单调不增 |

**一个必须写进代码的坑**：`Order=4` 是**全局**按被引排，不是「先按词筛再排」。
用 `content=滑坡&Order=4` 拿回来的前几条是《中国亏损上市公司盈余管理实证研究》——"滑坡"在这里是"业绩滑坡"。
但换成 `Title=滑坡&Order=4`，40 条里 39 条标题真的含"滑坡"。
→ **要"经典文献"，必须用 `Title=` 而不是 `content=` / `Theme=`。**

**覆盖的文献类型**（靠结果里那个裸 `<span>` 判断）：

| 检索方式 | 期刊 | 硕士 | 博士 | 会议 |
| --- | --- | --- | --- | --- |
| `Theme=` / `Title=` | 全 | 无 | 无 | 无 |
| `content=` | 有 | 有 | 有 | 有 |

学位论文网址在 `cdmd.cnki.com.cn`，会议在 `cpfd.cnki.com.cn`，期刊在 `www.cnki.com.cn`。
年鉴、专利**没测出来**（那两个词触发超时），方案里不承诺。

**年份筛选**：`Year=2024` 真生效（单值）；`Year=2024|2025` 只认第一个。
`PublishTimeBegin=2024-01-01` 这种日期格式**返回 0 条**，只认四位数年份。

### 不能用的

| 入口 | 状态 |
| --- | --- |
| `kns.cnki.net/kns8s/...` 现代检索 | 100% 被极验滑块挡（`verify/home?captchaType=blockPuzzle`）。带全套浏览器指纹头也一样 |
| 详情页完整摘要 | 恒定 128 字截断，div 里没有藏完整版，meta 里也没有 |
| `pay.cnki.net` 全文下载 | 302 到登录页，返回 HTML 不是 PDF |
| 百度学术 / 维普 / 万方 | 403 / 412 / 纯 JS 渲染抓不到 |
| 手机版 wap.cnki.net | 能开，多一个"机构"字段，摘要同样 128 字 |

### 登录为什么不做进插件

`~/carsi-bridge/` 那套的做法是 Playwright 驱动本机 Chrome 填表登录。插件里做不了，三个原因：

1. **插件是零运行时依赖的**（`dependencies: {}`）。塞 Playwright 进去要几百 MB，装插件的人全得跟着下。
2. **密码必须真实浏览器填**。金智 authserver 的密码用页面自己的 `encrypt.js` 加动态盐加密后写隐藏字段，`fetch` 拼 POST 一定失败。而"驱动浏览器"在 DSH 插件里没有可靠的跨平台实现。
3. **合规**。知网风控会封整所学校出口 IP 并可能停用学号。自动化批量下载不是插件该干的事。

**所以：插件只负责检索。登录与下载留给人。** 但可以做一件事降低摩擦——生成一条学校直登链接，用户点一下在系统浏览器里打开，自己登录、自己下。

## 二、方案（三层，都不碰密码）

### 第一层：内置检索（零配置，装上就能用）

新增 `lib/cnki.js`，纯函数 + 一个联网函数：

```
searchPapers({ query, field, order, year, page })  →  { items: [...], page, hasMore }
```

- `field`：`title`（经典文献用这个）/ `topic`（主题）/ `keyword` / `content`（能混出学位论文）
- `order`：`relevance` / `newest` / `cited` / `downloaded`
- 解析器按 `<div class="list-item">` 切块，块内抓字段。**不能**按 `checkbox1` 当块尾——它在块的最末尾、`data-fn` 在自己身上，用它当锚点会全空。
- 作者要滤掉 `data-key=""` 的空 a（每块都有一个）。
- 关键词取 `data-key` 的全串再按 `/` 分，单个 a 的文字只是其中一个词。

每条结果返回：

```js
{
  title, authors: [..], journal, issue, type,      // 期刊 / 硕士论文 / 博士论文 / 中国会议
  keywords: [..], cited, downloaded,
  url,                                              // 补上 https:
  excerpt,                                          // 正文开头约 120 字，不是摘要
  fn                                                // 知网文件名，如 GZKX202605014
}
```

### 第二层：一个路由 + 一段界面

- 路由 `paper.search`（不走 `source.search`——那条链路只支持 GET 模板，知网要 POST 表单）。
- 界面就加在导入面板的 `③ 找书` 后面，`④ 知网检索`：
  - 一个输入框 + 一个"怎么找"下拉（经典文献 / 最新发表 / 相关度 / 高下载）
  - 结果列表复用现成的 `.dr-candidate` 样式
  - 每条显示：标题、作者、期刊年期、**被引 N · 下载 N**、文献类型徽章
  - 每条后面两个动作：「打开知网页」（新标签打开，用户自己去下 PDF）、「复制题录」

### 第三层：学校直登链接（可选，用户自己配）

- `fsso.cnki.net/idp/list?federation=2` 是公开接口，1077 所学校，格式 `{"学校名": "1|https://idp.../idp/shibboleth"}`，`1|` 表示已开通校外访问。
- 用户在自己设置里选一次学校（或填 entityID），插件就存这一个**公开标识**。
- 面板上出现「从学校入口进知网」按钮，打开：
  `https://fsso.cnki.net/Shibboleth.sso/Login?entityID=<学校>&target=https%3A%2F%2Ffsso.cnki.net%2Fsecure%2Fdefault.aspx`
- **存的只是学校名和 entityID，不是密码。** 用户在浏览器里自己登录，插件永远不知道密码。

## 三、接口设计

| 方法 | 入参 | 出参 |
| --- | --- | --- |
| `paper.search` | `{ query, field?, order?, year?, page? }` | `{ items, page, hasMore, source:'cnki' }` |
| `paper.schools` | `{ keyword? }` | `{ schools: [{name, entityId, enabled}] }`（拉一次公开列表，按关键词过滤，缓存 24h） |
| `paper.school` | `{ entityId }` 或 `{ name }` | 存进 settings（一个 ≤200 字符的字符串） |

设置项新增一个键 `cnkiSchool`（string，≤200，空串合法）。
**注意**：`lib/store.js` 的 `rotateHistory` 会把 settings.json 复制进 `history/`，所以这个键只能放学校名/entityID 这种公开信息，绝不能放凭据。

## 五、验收

1. `node test/run.mjs` 全绿（现有 33 组 + 新增）。
2. `node golden/run.mjs` PASS 318/318 不动。
3. `node client/build.mjs --check` 通过。
4. 真机：导入面板出现「④ 知网检索」，搜「地质灾害」能出 20 条，被引数真实。
5. 搜「滑坡」切「经典文献」，前几条是真经典（20世纪以来中国的大型滑坡…被引 3019），不是"业绩滑坡"。
6. 学校入口能拉到 1077 所列表，选中后按钮能打开 fsso 直登页。
7. `npm pack` 的 tarball 里有 `lib/cnki.js`，**没有任何凭据文件**。

## 六、明确不做

- **不做自动登录**、不内嵌浏览器、不存密码、不存 cookie。
- **不做自动下载 PDF**。这是知网风控的红线，也是"插件该不该替全校人下文献"的边界。
- 不做漫游/代理、不绕验证码。
- 不承诺年鉴/专利覆盖（没测通）。
- 不承诺按作者精确检索（`Author=` 是松散匹配，跨学科混排）。
- 不改 `source.search` 那条已有的书源链路。
