## 本轮实测到的五个问题（细节与行号在计划书第二节）

1. **两套书源并存**：`settings.bookSources`（上限 8 条）+ `legado-sources.json`（盘上 2583 条），
   界面上两个「找书」入口。
2. **list 一次吐 3.66MB**：2583 条源的完整规则树全发给浏览器。前端只用五个字段，
   投影成四字段 + `usable` 布尔后是 298,416 B。
3. **大包导不进**：`lib/routes.js:2170` 只给 `shelf.import` 开了 200MiB 限额，
   `source.legado.import` 卡在 8MB。
4. **错误码吞成「出了点问题」**：全仓抛 93 个码，`client/src/api.js` 的表只有 47 条，
   未入表的 46 个码撞上 `MACHINE_PATTERNS` 第 9 条 `/\bE_[A-Z][A-Z0-9_]+\b/` →
   直接返回 GENERIC。实测六条（E_BODY_TOO_BIG / E_BOOK_NOT_FOUND / E_DISTILL_FAILED /
   E_NO_VAULT / E_LEGADO_EMPTY / E_SOURCE_MISSING）全部复现。
5. **深色下漏白卡片**：用户报的是「书源面板白底」，但把 `legado-ui.js` 的 30 个 `dr-*` 类
   逐个取最后一条 CSS 规则验过，**书源面板本身是干净的**（唯一字面量是遮罩
   `rgba(0,0,0,.42)`）。真凶在笔记面板：`--dsh-reading-ui-rule` / `-ui-bg-card` /
   `-mono` 三个变量**全仓从未定义**，`var()` 静默取字面浅色兜底 →
   `.dr-notes-row` 出 `#fbfaf7`、`.dr-notes-preview-text` 出 `#fff`。
   另 `:1065` `.dr-pagejump-input:focus` 用了不存在的 `--dsh-reading-accent`。
   修法：`CSS_TOKENS` 补三条别名定义 + 一处改名，三行 diff。

## 改了哪些文件

后端：

- `lib/legado.js` —— 加 `isUsableSource(source)`（`searchUrl` 非空且 `ruleSearch.bookList` 非空），
  list 投影与 prune 共用这一份判据，避免「界面说能用、点下去报缺规则」。
- `lib/store.js` —— 删 `bookSources` 相关读写；新增 `pruneLegadoSources()`（引用保护优先、
  没东西可删就不写文件）。
- `lib/routes.js` —— 删 `source.search` / `source.fetchPage`；`source.legado.list` 改成投影；
  `source.legado.import` 接 `prune` 并在返回体里带 `pruned: {removed, protected}`；
  导入限额从通用 8MB 提到 32MB / 180s。
- `lib/sources.js` —— 瘦身到只剩 `fetchSourceText`（候选抽取那套整段删）。

前端：

- `client/src/api.js` —— `humanizeError` 加通用解包（码前缀 + 中文，且不含机器语言时用后半句），
  补 `E_BODY_TOO_BIG` / `E_LEGADO_EMPTY` / `E_LEGADO_BAD_JSON` 三条文案，改 `E_SOURCE_NONE`。
- `client/src/legado-ui.js` —— 列表项判据改 `source.usable`；导入回执抽成 `importNotice(data)`，
  带「顺手清掉了 N 个用不上的源」。
- `client/src/shelf.js` —— 删「③ 找书」整段，换成指路块；`busy` 收成 `urlBusy`。
- `client/src/style.js` —— 补三个缺失别名；改错名 `--dsh-reading-accent`；删两个没人用的类。
- `client/src/app.js` —— 帮助文案三段式 + 书源面板那一段。

测试（45 → 48）：

- `test/legado_prune_test.mjs`（8 组）：引用保护压过「用不了 / 停用」、没东西可删时不重写文件、
  多次清理幂等、`meta.json` 坏掉时不影响清理。
- `test/humanize_test.mjs`（10 组）：未收录的码也能放出后半句、幂等、JSON / 路径 / 堆栈

- 老测试跟着改：`source_test.mjs` 删候选抽取的用例、`meta_test.mjs` 删 `bookSources` 用例、
