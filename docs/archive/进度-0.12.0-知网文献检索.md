### 队长：开工前的可行性实测（全部本机真跑，不是推测）

知网可达性探了 5 轮，结论收敛为：

| 结论 | 依据 |
| --- | --- |
| 老版检索站能用 | `POST search.cnki.com.cn/search/listresult` 200，100+ 次请求未触发限流 |
| 新版检索站不能用 | `kns.cnki.net` 全套浏览器指纹头也 302 到极验滑块 |
| 免费详情页只有 128 字摘要 | 抽查 12 篇不同年代学科，全部恒定截断 |
| 全文必须登录 | `pay.cnki.net/zscsdoc/download` 302 到登录页 |
| 百度学术/维普/万方都不行 | 403 / 412 / 纯 JS 渲染 |

字段能力实测：`Title=`/`Theme=`/`KeyWd=`/`Author=`/`content=` 有效；
`Type=`/`Subject=`/`Level=` 无效；`Year=` 单值有效多值只认第一个。

排序坑实测：`Order=4` 是全局排序。`content=滑坡&Order=4` 只有 4/20 条标题
真含「滑坡」（其余是「业绩滑坡」），`Title=滑坡&Order=4` 是 39/40。
