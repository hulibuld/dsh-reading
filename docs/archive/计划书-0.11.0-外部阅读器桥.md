# 计划书：0.11.0 外部阅读器桥

## 目标

dsh-reading 能连四类外部阅读器/工具，把书、论文、标注、笔记互相搬：
**Zotero（论文）→ KOReader（墨水屏标注）→ Calibre（电子书库）→ Obsidian（笔记库）**。
连上之后：书架上能「从 Zotero 导入」一篇论文、带已有高亮；能「从 KOReader 导入」一本书、带画线和进度；
能「从 Calibre 导入」一本 EPUB；能把读书卡与蒸馏稿写进 Obsidian vault。

成功判据：四个 `bridge.*` 路由能用；假服务/假目录的测试全绿；`node test/run.mjs` 不红；client 重建一致。

## 步骤

1. **P0 框架**：`lib/bridges/index.js` 注册表 + `lib/bridges/http.js` 本机 HTTP 客户端 + 四个路由的骨架
   → 验证：`bridge.detect` 对不存在的服务返回 `{ ok: false }`，有单测。
2. **Zotero 检测与列表**：`detect()` 探 `127.0.0.1:23119/api/`；`list()` 取分类与条目
   → 验证：假 HTTP 服务返回固定 JSON，断言分类与条目字段。
3. **Zotero 导入**：取附件 PDF → 走 `store.importBook` → 标注落成批注（带页码）
   → 验证：假服务 + 真 PDF fixture，导入后书架有书、批注条数对。
4. **KOReader**：扫 `*.sdr/metadata.*.lua`，写一个 Lua 表字面量解析器
   → 验证：夹具目录里造一个 .lua，断言划线/注/进度。
5. **Calibre**：`calibredb list --for-machine` 的 JSON fixture；导入 `formats` 里的文件
   → 验证：注入假执行器，断言列表与导入。
6. **Obsidian**：写 `dsh-reading/读书卡/`，同名更新不重复
   → 验证：临时目录写两次，断言只有一个文件且内容更新。
7. **界面**：书架「外部」按钮 + 四行面板（状态、导入按钮）
   → 验证：`node client/build.mjs` 重建、页面刷新后面板出现。

## 不做什么

- 不模拟点击外部软件界面；不读别人的 SQLite；不自动启动别人的软件。
- Zotero 写回（需用户 Web API key）不进本期。
- 标注位置精确对齐（页面坐标 ↔ CFI）不做。
- 不接微信读书、得到、多看、掌阅、MarginNote、Apple Books、Kindle。
